
# FindIt - Design System

## 1. Project Overview

FindIt is a Student Lost and Found application designed to help students report missing belongings and reconnect with lost items.

## 2. Color Palette

| Color | Hex Code | Usage |
|---|---|---|
| Primary Blue | #2563EB | Buttons and links |
| Dark Blue | #172554 | Headings and footer |
| Background | #F5F7FB | Main background |
| Light Blue | #EAF1FF | Hero section |
| White | #FFFFFF | Cards and forms |
| Text Gray | #64748B | Secondary text |
| Dark Text | #1E293B | Main text |
| Error Red | #DC2626 | Logout button |

## 3. Typography

- Font Family: Arial, sans-serif
- Main Heading: 48px
- Section Heading: 30px
- Card Heading: 20px
- Body Text: 16px
- Small Text: 12px

## 4. Components

### Navigation Bar
Contains the FindIt logo, navigation links, and login/logout options.

### Hero Section
Introduces the application and provides buttons to report or browse lost items.

### Complaint Card
Displays item name, photograph, location, date, description, and contact option.

### Complaint Form
Allows students to submit lost item information and upload a photograph.

### Student Profile
Displays the logged-in student's name, email, phone number, and logout option.

### Authentication Pages
Includes separate Login and Sign Up forms.

## 5. Buttons

- Primary buttons use blue backgrounds and white text.
- Secondary buttons use white backgrounds with blue borders.
- Buttons have rounded corners.
- Hover effects provide visual feedback.

## 6. Layout and Spacing

- Flexbox is used for navigation and profile layouts.
- CSS Grid is used for complaint cards.
- Cards use rounded corners and subtle shadows.
- Sections use consistent spacing and padding.

## 7. Responsive Design

The application supports desktop, tablet, and mobile screens.

- Desktop: Three complaint cards per row.
- Tablet: Two complaint cards per row.
- Mobile: One complaint card per row.

## 8. Design Principles

- Simple and clean interface.
- Easy navigation.
- Consistent colors and typography.
- Readable content.
- Responsive layouts.
- Student-friendly experience.
